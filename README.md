# Sales Data Analysis Using SQL

## 1. Project Overview
This project analyzes sales data using SQL and PostgreSQL to identify sales trends, customer purchasing behavior, and product performance.

## 2. Objective
- Calculate total sales and total orders.
- Identify top-performing products.
- Analyze city-wise and category-wise sales.
- Understand customer spending patterns.
- Identify repeat customers.

## 3. Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

## 4. Database Tables
1. **Customers** – Customer details such as ID, name, city, and email.
2. **Products** – Product details such as ID, name, category, and price.
3. **Orders** – Order details including customer, product, date, and quantity.
4. **Payments** – Payment details including order ID, amount, and payment date.

## 5. SQL Concepts Used
- SELECT
- WHERE
- JOIN
- GROUP BY
- ORDER BY
- Aggregate functions (SUM, COUNT, AVG, MAX)
- HAVING
- Subqueries

## 6. Key Findings
- Total Sales: ₹183,500
- Total Orders: 8
- Highest Revenue Product: Laptop (₹110,000)
- Best-Selling Product by Quantity: Headphones (5 units)
- Highest Sales City: Chennai (₹76,000)
- Highest Spending Customer: Arun (₹75,000)
- Highest Sales Category: Electronics (₹175,000)
- Average Order Amount: ₹22,937.50

## 7. Conclusion
This project demonstrates how SQL can be used to analyze sales data, identify business trends, and generate useful insights to support business decisions.

*Note: The analysis uses a sample dataset created for this project.*
