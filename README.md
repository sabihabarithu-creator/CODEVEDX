 # HR Analytics Using SQL

## Project Overview
This project analyzes employee data using PostgreSQL to understand workforce distribution, salary patterns, department performance, and employee experience.

## Tools Used
- PostgreSQL 18
- pgAdmin 4
- SQL

## Dataset
The project uses a sample dataset containing 12 employee records with details such as:
- Employee ID and Name
- Age and Gender
- Department and Job Role
- Monthly Salary
- Hire Date
- Years of Experience

## Analysis Performed
1. Total employee count
2. Department-wise employee count
3. Average salary by department
4. Highest-paid employee
5. Department-wise salary expense
6. Gender-wise employee count
7. Experience analysis
8. Year-wise hiring trends
9. Salary ranking
10. Highest-paid employee by department
11. Above-average salary analysis
12. Experience-level analysis
13. Minimum and maximum salary
14. Salary gap analysis
15. Annual salary calculation
16. Job role-wise analysis

## Project Files
- `hr_analytics.sql` – SQL table creation, sample data, salary updates, and analysis queries.
- `README.md` – Project documentation.

## Note
This project uses illustrative sample employee data for SQL learning and analysis. Salary values are not actual company salary records.
