 # Customer Behavior Analysis Using SQL

## Project Overview
This project analyzes customer purchasing behavior using SQL. It helps identify customer spending patterns, repeat customers, popular products, and sales trends.

## Objectives
- Analyze customer purchasing patterns.
- Identify repeat customers.
- Find the most purchased products.
- Calculate total revenue and average order value.
- Analyze city-wise and category-wise sales.
- Identify top-spending customers.

## Tools Used
- PostgreSQL 18
- pgAdmin 4
- SQL

## Database Tables
1. **Customers** – Stores customer details such as name, age, gender, city, and signup date.
2. **Products** – Stores product names, categories, and prices.
3. **Orders** – Stores customer orders, dates, and total amounts.
4. **Order Items** – Stores products and quantities in each order.

## SQL Concepts Used
- CREATE TABLE
- INSERT
- UPDATE
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- HAVING
- JOIN
- Aggregate Functions
- Subqueries
- Window Functions
- Date Functions

## Key Findings
- Total customers: 8
- Total orders: 10
- Total revenue: ₹1,66,600
- Average order value: ₹16,660
- Arun and Priya are repeat customers.
- Headphones are the most purchased product by quantity.
- Laptop generates the highest product revenue.
- Chennai has the highest number of customers.

## Conclusion
This project demonstrates how SQL can be used to analyze customer behavior and extract useful business insights from structured data.
